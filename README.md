# sdos

The density of states of a big sparse matrix, in one call.  Order-N stochastic trace estimation with the kernel polynomial
method (KPM) or maximum entropy; real symmetric or complex Hermitian; explicit or matrix-free; standard `A x = λ x` or
generalized `A x = λ B x`; electrons or phonons.

Status: **0.1.0, first public release.**  The method, its tests against dense diagonalization and an independent code, benchmarks up to
millions of atoms, and the limits of the approach (what does not scale) are described in the report in `paper/` (REVTeX source and bibliography).
Docs: `docs/guide.md`, `docs/theory.md`.  Tests: `pip install -e ".[test]" && pytest`.

**In short.**  `sdos` estimates the density of states of a large sparse Hermitian matrix (or a generalized problem with an overlap or mass matrix)
from Chebyshev moments computed with random vectors, so the cost grows linearly with the matrix size.  The density is reconstructed by the kernel
polynomial method or by maximum entropy, and the same moments give band energies, Fermi levels, local and projected densities and harmonic
thermodynamics.  Interfaces: tight-binding and DFTB Hamiltonians, SIESTA through sisl, and matrix-free LAMMPS Hessians for phonons.
The underlying methods are due to Silver, Röder, Kress, Voter, Drabold, Sankey and collaborators; the report states what is added.

## Install

    pip install sdos                 # from PyPI (numpy and scipy are the only requirements)
    pip install -e ".[test]"        # from a clone, to run the tests; add [plot] for matplotlib, [amg] for the AMG preconditioner

## The simple way

```python
import sdos
res = sdos.dos("H.npz")            # a file (triplets, Matrix Market, .npz), a SciPy sparse matrix, an array, or a LinearOperator
res.plot()                         # DOS with error bars
E, rho = res.E, res.rho            # rho: per orbital, integrates to 1 (multiply by N for states per unit energy)
res.save("dos.txt")
```

Real or complex is detected, defaults are sensible (256 moments, 10 random vectors, first 4 moments exact), and nothing else is
needed.  From the shell:  `sdos H.npz -o dos.dat --plot dos.png`.

**Input.**  The simplest matrix file is plain text, one entry per line, `i j a_ij` (a fourth column is the imaginary part).
Give one triangle or both; 0- or 1-based indices and the storage are detected automatically, and the other triangle is
generated by conjugation.  Matrix Market and SciPy `.npz` also work.

**Save, then analyse later.**  The DOS stage needs only the matrix.  Save everything it produced (DOS, error bars, moments,
spectral window, settings) and analyse it afterwards, with no matrix:

    sdos H.dat -o result.npz                          # a .npz name saves the full result
    sdos analyze result.npz --valence-file Z.txt      # electrons: E_F and band energy (Z of each atom, one per line)
    sdos analyze result.npz --electrons 4096 --spin 2
    sdos analyze phonons.npz --thermo 10 1000 50      # vibrations: ZPE, U, F, S, Cv (result made with --omega)
    sdos analyze result.npz --moments 60 --method maxent -o dos.txt   # re-reconstruct from the saved moments

In Python: `res.save("result.npz")`, `res = sdos.load("result.npz")`.  The DOS is generic; electron counts, spin and
temperature enter only in the analysis step.

```python
sdos.dos(H, resolution=0.05)       # choose the energy resolution instead of the number of moments
sdos.dos(H, quick=True)            # fast look: 128 moments, 4 vectors
sdos.dos(H, B=S)                   # generalized problem: overlap S (sparse), or masses (1-D array)
res = sdos.vdos(Phi, mass=m)       # phonons: res.omega, res.g (= 2 w rho(w^2)); negative lambda are reported, never clipped
```

## All the extras, when you need them

Every option below is a keyword of `sdos.dos` / `sdos.estimate_dos` (and a flag of the `sdos` command).

| you want | use |
|---|---|
| sharper features from few moments | `method="maxent"` (with moment uncertainties and jackknife errors) |
| damping kernel | `kernel="jackson"` (default) or `"lorentz"` (a Green-function kernel: it spikes at the window edges for a DOS) |
| lower noise in band energy / Fermi level | `exact_moments=K` (local O(N) method, unbiased; standard or diagonal B), or `vectors="impartial"` (Drabold-Sankey, first 3 moments exact per vector) |
| variance reduction by probing | `probe=d` (distance-d coloring: moments n ≤ d exact) |
| other random vectors | `vectors="phase" / "rademacher" / "gaussian" / "impartial"` |
| generalized problem `A x = λ B x` | `B=...`; `binv="pcg"` (default; `precond="block-jacobi"`, `"ic"` incomplete Cholesky, `"amg"`, `"none"`, experimental `"ilu"`) or `binv="chebyshev"` (fixed polynomial B⁻¹) |
| per-site blocks | `block_size=4` (orbitals per atom) for block-Jacobi / scaling |
| a window with sharp levels | `sdos.shift_invert_dos(A, (E1, E2))` — **not O(N)** |
| Fermi level and band energy | `sdos.fermi_and_band_energy(res, n_electrons)` |
| eigenstates in a window + IPR | `sdos.window_eigs(A, B, (E1, E2), method="filter")` (scalable) or `"shift-invert"` (exact, not O(N)) |
| local / projected DOS (Mulliken for B != 1) | `sdos.pdos(A, B, groups=...)`, `sdos.ldos(A, B, orbitals=...)` |
| phonon thermodynamics | `sdos.vdos(Phi, mass=m, zero_modes=3)` then `sdos.harmonic_thermo(res, T)` |
| DOS from forces only (e.g. LAMMPS) | `sdos.interfaces.lmp.HessianOperator` + `sdos.vdos(op, hermitian_tol=1e-3)` |
| H(k), S(k) from SIESTA/sisl | `sdos.interfaces.sisl_if.from_sisl(H, k)` |

## What to know

* The Lanczos spectral bounds are estimates inside the spectrum; the default 1% margin covers the usual error and a warning is
  issued if a moment exceeds 1 (bounds too tight).  Pass `bounds=(Emin, Emax)` for guaranteed values (Gershgorin: `sdos.spectral_bounds(A, "gershgorin")`).
* Generalized problems: exact local moments and impartial vectors need a local operator and are refused for a non-diagonal B.
  Probing is not available for them.  A diagonal B (masses) is mass-weighted once and no solves are done.
* Shift-invert windows factorize `A - σ`; the fill grows superlinearly in 3D, so they are not O(N).
